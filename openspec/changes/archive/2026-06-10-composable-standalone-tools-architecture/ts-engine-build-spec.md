# TS Retirement + Rewire Build Spec (tasks 4.2, 4.3, 4.4, 7.7)

Synthesized from the `ts-engine-build-spec` design workflow (5 agents, 2026-06-07), grounded in the real engine/adapter/sdk/server code + the gate's built subscribe wire + the Rust gate-client mirror. TDD; one commit per build unit. Clears the engine TS red (currently failing on BOTH `bun test` and `tsc` check-types).

## Resolved decisions (accepted from design openDecisions)

- **Engine ingress seam:** an optional `HookSource` port in `@athing/sdk` `ports.ts`, added to `EngineDeps`, consumed by the proxy in `start()` (symmetric with the existing `DaemonTransport` port; keeps the engine transport-agnostic). `EngineDeps.hookSource` is **optional** so apps/ui + apps/cli stay green without wiring a gate client.
- **payload->ContentEvent mapper:** a pure contract function in `@athing/sdk` (deterministic map over contract types). v1: `PostToolUse -> ToolUseContent{sessionId,toolName,toolInput}`; all other kinds -> null (ADR-0017: usage/edit content dropped with the transcript).
- **Subscribe-wire mirror:** new `@athing/sdk` `subscription.ts` mirroring `packages/gate-client/src/lib.rs` byte-for-byte (4-byte BE length prefix + JSON frame `ready|event|error`; `HOOK_SUBSCRIPTION_WIRE_VERSION`). **Web APIs only** (`Uint8Array`/`DataView`/`TextDecoder`, no `Buffer`) per the sdk+engine web-api-only rule. Pinned by a golden cross-check reading the shared `packages/gate-client/tests/fixtures/*.json`.
- **FileSource orphan:** removing the transcript reader orphans `fileSource`/`agentHome` in `EngineDeps` (removed end-to-end here) and the `FileSource` port + `BunFileSource`/`TauriFileSource` impls (left as unused for a separate follow-up cleanup; unused TS exports don't break builds).
- **`ATHING_BRIDGE_URL` spawn-env plumbing:** left untouched here (the gate cutover is 7.6, out of scope for 4.x/7.7).
- **Env names:** `ATHING_SESSION_ID`/`ATHING_SESSION_TOKEN` (canonical; reconcile in 7.4).

## Build order (each unit: `bun test` AND `bun run check-types` green before commit — bun test does NOT type-check)

2. **Drop parse fns from AgentDefinition; reduce adapter to declarative config** [4.4, adapter half of 4.2] — remove `parseHook`/`transcriptPath`/`parseTranscriptEntry` from `AgentDefinition` (`sdk/src/types/adapter.ts`) + drop unused HookEvent/ContentEvent import; DELETE `adapter-claude-code/src/{parse-hook,parse-entry,transcript-path}.ts` + their 3 test files; prune `adapter-claude-code/src/index.ts` (keep claudeCode declarative config, setup, SUPPORTED_CLI_VERSION_RANGE, BINARY_RESOLUTION); fix `import-safe.test.ts`; strip the 3 parse fields from the `mockAdapter` literal (`engine/tests/proxy.test.ts`) and the `bashAdapter` literal (`tests/integration/fixtures/bash-adapter.ts`). 4. **Server-hosted TS gate-client** [7.7] — NEW `apps/server/src/gate-client.ts`: connect to the gate subscribe socket, `encodeSubscribeRequest`, feed chunks to `FrameDecoder`, `negotiateReady`, yield a per-session `AsyncIterator<HookEvent>` (host layer — Bun socket APIs allowed; takes socket path as a param so it's unit-testable). 5. **Engine HookEvent -> status + content mapping + server feed** [7.7] — add the `HookSource` port (`sdk/ports.ts`) + optional `EngineDeps.hookSource`; proxy `start()` subscribes, calls `statusMapper.apply(event)` (restores status + send-queue gating) and the pure `hookEventToContent` mapper -> contentHandlers; re-add the deleted coverage driven via the new ingress (UserPromptSubmit->WORKING, IDLE-after-WORKING flush, PostToolUse->ToolUseContent, per-session isolation); wire `apps/server/src/index.ts` to build the gate-client into a HookSource + inject, **guarded by ATHING_GATE_URL presence** so it's inert until 7.4 injects env + registers the session. Keep ui/cli green (hookSource optional).

## Cross-cutting risks

- Dual RED planes: run BOTH `bun test` and `bun run check-types` each unit — bun test hides tsc failures.
- EngineDeps blast radius: fileSource+agentHome removal breaks apps/server/ui/cli + integration under tsc unless all updated in step 1's commit (each turbo package has its own check-types).
- Interface vs object-literal: shrink AgentDefinition + all 3 literals (claudeCode/mockAdapter/bashAdapter) together (TS2353).
- Ordering: step 1 (delete TranscriptReader) MUST precede step 2 (drop the interface methods it calls).
- 7.7 live path (real socket, register-before-spawn, env) is 7.4/7.5/7.6 — guard the server feed behind ATHING_GATE_URL + verify with a fake HookSource until then.
- sdk web-API-only: subscription.ts uses Uint8Array/DataView/TextDecoder, never Buffer.
- Cross-language wire drift: sdk mirror must stay byte-identical to gate-client + contracts (camelCase, adjacency-tagged type+payload, 4-byte BE prefix, WIRE_VERSION=1); pin via shared golden fixtures.
- Content fidelity loss (ADR-0017 accepted): only PostToolUse->ToolUseContent; usage/edit gone in v1.
- proxy.test.ts churns in steps 1, 2, 5 — sequence + re-run after each.
